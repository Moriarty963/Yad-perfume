Приватность YAD Club

Регистрация пока готовится к запуску. До включения личных кабинетов здесь будет опубликована полная политика обработки персональных данных с реквизитами оператора и условиями их хранения. Этот документ не является окончательной юридической политикой.

Какие возможности запланированы

Покупатели смогут регистрироваться с помощью подтверждения адреса электронной почты, управлять своим именем и добровольно подписываться на рекламные сообщения. По умолчанию рассылка выключена.

Какие данные потребуются

Имя для профиля, адрес электронной почты, техническая информация о входе и история выбора рекламной подписки. Данные должны храниться с соблюдением применимых требований законодательства.

Управление данными

В личном кабинете будет возможность отключить рекламу, выйти из аккаунта и удалить профиль. Информация о заказах, оформленных без регистрации, будет обрабатываться отдельно.
